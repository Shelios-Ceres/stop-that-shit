# Triage labels

| Role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate |
| needs-info | needs-info | Waiting on the reporter |
| ready-for-agent | ready-for-agent | Specified and ready for implementation |
| ready-for-human | ready-for-human | Requires human work |
| wontfix | wontfix | Will not be actioned |

Category labels are `bug` and `enhancement`. A triaged issue carries one category
and one state label. Check existing labels before applying a state; this mapping
does not itself create labels or change issues.
